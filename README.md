# fffzfzfFrRf# بات اخبار اقتصادی جهان برای تلگرام

این بات به‌صورت خودکار (روی گیت‌هاب، کاملاً رایگان) اخبار مهم اقتصادی جهان رو از چند منبع RSS
چک می‌کنه، با کمک هوش مصنوعی رایگان (Gemini) تشخیص می‌ده کدوم خبر واقعاً مهمه، اون رو به فارسی
روان ترجمه می‌کنه، و همراه با عکس (در صورت وجود) تو کانال تلگرامت پست می‌کنه.

## مراحل راه‌اندازی

### ۱. ساخت بات تلگرام
1. تو تلگرام به @BotFather پیام بده.
2. دستور `/newbot` رو بفرست و اسم و یوزرنیم بات رو انتخاب کن.
3. یه توکن بهت می‌ده، شبیه `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — نگهش دار.

### ۲. ساخت کانال و اضافه کردن بات
1. یه کانال تلگرام بساز (عمومی یا خصوصی).
2. بات رو به عنوان ادمین کانال اضافه کن (با دسترسی ارسال پیام).
3. اگه کانال عمومیه، آیدی کانال چیزیه مثل `@my_channel_name`.
   اگه خصوصیه، باید عددی شبیه `-1001234567890` رو پیدا کنی (می‌تونی از باتی مثل @username_to_id_bot کمک بگیری).

### ۳. گرفتن کلید رایگان Gemini
1. برو به aistudio.google.com/app/apikey و با حساب گوگل وارد شو.
2. روی «Create API key» بزن و کلید رو کپی کن (بدون نیاز به کارت اعتباری، کاملاً رایگان).
3. این سرویس محدودیت روزانه رایگان داره ولی برای این حجم استفاده کاملاً کافیه.

### ۴. ساخت ریپازیتوری گیت‌هاب
1. یه ریپازیتوری جدید و public بساز.
2. تمام فایل‌ها (bot.py, requirements.txt, posted.json, .github/workflows/news-bot.yml) رو آپلود کن.

### ۵. اضافه کردن Secrets
تو ریپو برو به: Settings → Secrets and variables → Actions → New repository secret
سه تا Secret بساز:
- BOT_TOKEN → توکنی که از BotFather گرفتی
- CHANNEL_ID → آیدی کانالت
- GEMINI_API_KEY → کلیدی که از Google AI Studio گرفتی

### ۶. فعال کردن و تست
- بات هر ۳۰ دقیقه یه‌بار خودکار اجرا می‌شه.
- برای تست سریع: تب Actions → workflow «Economic News Bot» → دکمه Run workflow.

## تنظیمات قابل تغییر (داخل bot.py)
- RSS_FEEDS → لیست منابع خبری
- پرامپت داخل ask_gemini → معیار «خبر مهم»
- MAX_POSTS_PER_RUN → حداکثر تعداد پست در هر اجرا
- MAX_CANDIDATES_PER_RUN → حداکثر تعداد خبر بررسی‌شده در هر اجرا

## نکات
- posted.json تاریخچه لینک‌های بررسی‌شده رو نگه می‌داره؛ خودکار commit می‌شه.
- تاخیر چند دقیقه‌ای کرون گیت‌هاب طبیعیه.
- همه‌چیز رایگانه: RSS، Bot API تلگرام، Gemini API، GitHub Actions روی ریپوی public.
